# 안녕하세요, Dchat26입니다 👋

**보안을 아는 IoT 개발자**를 목표로 합니다.
정보보호학을 전공했고, 앱·서버·하드웨어를 연결해 서로 다른 기기를 하나로 제어하는 시스템을 만들고 싶습니다.
